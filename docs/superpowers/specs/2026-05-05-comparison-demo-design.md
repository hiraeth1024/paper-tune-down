# 首页真实案例对比展示 — 设计文档

日期: 2026-05-05

## 概述

在首页新增真实案例对比区域，使用 `/frontend/assets/` 下的四张截图展示 AIGC 率和段落疑似度的前后对比效果。

## 设计

### 位置

HowItWorks 与 QASection 之间。

### 布局

桌面端两栏（`grid-cols-2`），移动端堆叠。每栏一张对比卡。

### 左卡：AIGC 检测率对比

- 上方并排两张图片：改写前-1.png（左）、改写后-1.png（右），中间箭头分隔
- 下方文字：「AIGC 总体疑似度从 **81.3%** 降至 **24.79%**，降幅 **69.5%**」
- 图片带圆角边框阴影

### 右卡：段落疑似度对比

- 上方并排两张图片：改写前-2.png（左）、改写后-2.png（右），中间箭头分隔
- 下方文字：「单段最高疑似度从 **98.51%** 降至 **64.29%**，降幅 **34.7%**」

### 区域标题

「真实案例效果对比」
副标题：「以下为实际论文处理前后的 AIGC 检测与段落查重结果对比」
